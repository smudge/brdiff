brdiff

Blue-red luminance difference

Blue indicates greater luminance in the base image; red indicates greater luminance in the subtraction image. Similar pixel values approach black.

Unlike an unsigned grayscale difference, the colors preserve which image was brighter. This can help highlight materials in multispectral image subtraction. Both images must have the same dimensions.
